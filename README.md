# One-Line Office Joke

Entry for the make.fun competition **"One-Line Office Joke: 24-Hour Sprint"**
(`u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162`).

## What it does

`main.py` (Python 3, standard library only) writes a single one-line joke
about office life to `/output/entry.txt` — no trailing newline, well within
the 200-character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## The joke

> I got promoted: same desk, same pay, but now the meetings I hated are the ones I have to run.
